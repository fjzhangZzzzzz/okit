# Repository development rules

These rules apply to all changes in this repository.

## Branch and merge workflow

- Do not develop, commit, or push changes directly on `main`.
- Before modifying files, confirm the current branch. If it is `main`, create and switch to a
  purpose-specific `feature/*` branch first.
- Keep each branch focused on one independently reviewable change.
- Merge changes into `main` only through a Pull Request.
- Do not bypass required review or repository checks when merging a Pull Request.
