# 测试与 TDD

每个行为变更遵循 Red → Green → Refactor：先编写失败的公开接口测试，再以最小实现使其通过，最后在全套测试通过的前提下整理代码。

测试以 CLI 为主要接缝，验证每一级 `--help`、参数、stdout、stderr、退出码以及结构化输出。帮助测试还必须证明不会初始化功能状态或执行外部操作。

MobaXterm 检测、主题和许可证，以及安装、升级、卸载均应在进程内或受控临时目录中验证。文件系统、时间、环境变量、外部进程和 Windows 注册表通过小接口注入；不得依赖真实用户目录或修改开发机配置。

发布冒烟测试在干净环境执行 README 的安装入口，再验证 `--version`、`--help`、`upgrade --help` 和 `uninstall --help`。生命周期测试从上一稳定版升级到待发布版本，覆盖失败回滚、保留用户数据的卸载与 `--purge` 卸载。升级源必须提供顶层 `upgrade` 命令；脚本不会回退到旧命令，不支持的版本会在升级前明确失败。

完成前必须通过适用平台的测试、`go test ./...`、格式化和静态检查。
