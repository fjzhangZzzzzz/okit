# ADR 0002：统一 CLI 结构

- 状态：已接受
- 日期：2026-07-18

## 决策

命令采用“名词功能 + 动词动作”结构。顶层命令固定为 `info`、`hex`、`pe`、
`git-sync`、`shell`、`mobaxterm` 和 `self`；MobaXterm 的主题与许可证统一放入同一命名空间，
产品自身的升级与卸载统一放入 `self`。

命令树、参数解析和分层帮助统一使用 Cobra 实现，业务包不依赖 Cobra。项目继续使用
自身的配置存储，不因采用 Cobra 而引入 Viper；只有配置来源和优先级明显复杂化时才
单独评估配置框架。

全局输出、退出码和安全参数由 [`../cli.md`](../cli.md) 定义。新增功能必须具有明确
边界和独立功能文档，不引入运行时插件发现机制。

## 原因

旧名称混合缩写、实现细节和产品名，命令层级不一致。手写参数分发还会造成子命令帮助、
错误格式和参数校验不一致。显式、稳定且声明式的命令树更易发现、测试和长期演进。

## 影响

Go 版本不保证旧 Python 命令名兼容。稳定版发布后的破坏性命令变更遵循语义化版本。
新增命令必须提供上下文帮助和命令测试；不得在 `--help` 路径初始化外部服务或修改状态。
