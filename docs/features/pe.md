# pe

## 功能目标

解析 PE32/PE32+ 文件并展示 DOS 头、COFF 头、可选头和节表等基础信息，不执行
目标文件。

## 使用场景

```text
okit pe inspect app.exe
okit pe inspect app.exe library.dll --format json
```

## 行为规则

- 使用 Go 的 PE 解析能力读取文件结构，不启动或加载目标程序。
- 表格输出适合人工查看；JSON/CSV 输出字段名稳定，适合脚本消费。
- 多文件结果包含来源路径；按输入顺序输出。
- 单文件无效时继续处理其余文件，并返回部分成功。
- 至少输出机器类型、时间戳、特征、入口点、镜像基址和节信息。

## 平台差异

解析功能在 Linux 和 Windows 上保持一致，不依赖 Windows API。

## 错误与安全

截断、签名错误、不支持的可选头和权限错误必须区分报告；禁止执行输入文件。

## 验收标准

- `PE-001`：正确解析 PE32 与 PE32+ 固定样本。
- `PE-002`：表格、JSON、CSV 包含约定字段。
- `PE-003`：损坏和截断文件不会导致崩溃。
- `PE-004`：多文件部分失败返回退出码 `3`。
- `PE-005`：Linux 与 Windows 对同一样本产生等价结构化结果。
