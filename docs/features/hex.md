# hex

## 功能目标

跨平台查看文件的字节内容，覆盖常用十六进制、八进制、字符和十进制展示场景，
不修改输入文件。

## 使用场景

```text
okit hex app.bin
okit hex app.bin --skip 512 --length 128
okit hex app.bin --display hex --word-size 2
```

## 行为规则

- 默认使用 canonical 格式，同时显示偏移、十六进制字节和可打印 ASCII。
- 支持一字节和二字节分组；二字节数值按目标实现明确的固定小端解释。
- `--skip` 从文件开头跳过字节，`--length` 限制读取字节数。
- 默认压缩连续重复行；`--no-squeeze` 输出全部行。
- 多文件按输入顺序处理。任一文件失败时继续处理其余文件，并返回部分成功。
- 读取应采用流式处理，不按文件大小一次性载入内存。

## 平台差异

Linux 和 Windows 行为一致；输出使用 `/` 或 `\` 不应影响结果内容。

## 错误与安全

目录、缺失文件、无权限和无效数值参数必须产生明确错误。命令永远以只读方式打开
输入文件。

## 验收标准

- `HEX-001`：默认输出包含正确偏移、字节和 ASCII。
- `HEX-002`：skip 与 length 精确限制读取范围。
- `HEX-003`：所有 display 与 word-size 组合产生确定结果。
- `HEX-004`：重复行压缩可通过 `--no-squeeze` 禁用。
- `HEX-005`：大文件以有界内存处理。
- `HEX-006`：多文件部分失败返回退出码 `3`。
